### Issue tracker

Issues are tracked in GitHub at `FitBBC/token-market-cli`. Because this workspace is not currently a Git clone, always pass `--repo FitBBC/token-market-cli` to `gh`. See `docs/agents/issue-tracker.md`.

Use the five canonical triage labels unchanged: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.
