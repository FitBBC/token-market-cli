# Token Market 桌面 UI 探索

用户请求：看现有工具并设计一套 UI。用户偏好原话：「沿用现有 Logo，你来设计」。当前阶段仅交付三方向可交互原型，等待选择；不覆盖 src/、Rust 或用户已有改动。

## 真实内容与共同尺寸
- 产品：Token Market，Tauri 桌面工具。现有默认窗口 900×760，可缩放。三版统一 1440×1000 展示截图，兼容 900×760 和 375×812。
- 使用者：使用 AI 编码工具的中文用户，需要连接服务而非理解配置文件。
- 核心任务：浏览器登录、切换当前空间、查看余额、检测六款工具、连接/重新接入、选择配置模型、确认后测试、打开工具、安全取消接入。
- 六款工具：Claude Code / Codex CLI / WorkBuddy / DeepSeek Harness / OpenClaw / OpenCode。官方资产在 assets/brands.json（data URI）。全部图片内嵌。
- 明确区别当前空间（新连接使用）与已连接工具自己的计费空间；切换空间不迁移已有连接。
- 安装、已配置、文本测试通过、文本测试失败、配置变化、未安装要能区分。绿=通过，红=失败；不能声称配置完成等于模型测试通过。
- 原型示例数据：演示账号、个人空间/团队空间，余额 ¥128.60（演示）。Claude Code 已配置文本测试通过，Codex CLI 已配置未测试，WorkBuddy 已安装未接入，DeepSeek Harness/OpenClaw/OpenCode 未安装。统一标明「交互原型 · 演示数据」，不读取本机私有配置、不调用真实 API、不启动工具、不产生费用。
- 模型名 glm-5.3 来自当前仓库的生产配置文档；模型数量/其他模型只作为演示，不展示未经验证的平台指标。
- 页面最小要求：首页工具管理完整首屏，搜索/状态过滤，工具详情（模型和计费空间）、模拟接入、测试前确认（多模型选择）、模拟启动、切换空间。登录视图可作为可切换演示状态。
- 按钮至少 44×44；正文≥14，说明标签≥12；系统中文无衬线，适当等宽用于模型标识。基本键盘焦点、Escape 关闭 dialog。
- 不做营销落地页、虚构排行榜、使用量图表、收入统计、AI 聊天输入框。
