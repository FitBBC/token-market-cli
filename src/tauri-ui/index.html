开始使用

  1. 安装你常用的工具

    安装完成后，返回首页点击“重新检测”。

  2. 确认空间，然后接入

    接入会配置模型，当前空间用于这次新连接的计费归属。

  3. 重新打开工具

    已有会话请先退出，让工具读取新的模型配置。

  4. 需要时，测试一次

    连接详情中可发起文本测试，确认费用后才发送请求。

常见问题

接入后为什么显示“未测试”？

接入只配置工具，不会自动发送模型请求。测试由你单独发起，可能产生费用。

切换空间会影响已有工具吗？

已有工具保持自己的计费空间。需要更换归属时，在连接详情中重新接入并确认目标空间。

退出登录会删除工具配置吗？

不会。退出桌面账号不会重写已有 Agent 配置。

文本测试通过代表什么？

表示一次完整文本输出成功。流式输出、工具调用和 Agent 运行表现需要在实际工具中确认。

配置变化后为什么不能测试？

配置可能与接入记录不一致。请检查配置或重新接入，以确保测试使用正确的连接。
